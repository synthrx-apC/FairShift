# 4-minute demo script

1. Open the worker app at `http://localhost:5173`; show the large check-in/out actions and synthetic signed-receipt label.
2. Open **My pay** and explain the transparent base-pay/overtime breakdown and demo-rule disclaimer.
3. Submit a hazard report using an icon/category and zone; show it appear in the admin Safety & Escalations queue at `http://localhost:5174`.
4. Change the report status from Open to Seen or In progress; refresh the worker view to show status tracking.
5. In admin, switch sector pack from Construction to College, then Hospital (simulated draft). Explain that terminology and defaults change by pack.
6. Show the site-level fairness score and explain that the data is synthetic. Reset demo data before the next run.
